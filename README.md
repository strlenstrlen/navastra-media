# Navastra Media

Public, production-ready media used by Navastra's social publishing workflows.

This repository intentionally contains only finalized public-facing creative. Campaign strategy, working files, source data, credentials, and private operational material remain in private repositories.

## Campaigns

- [`initial-social/`](initial-social/) — launch campaign assets for Instagram and X

## Stable media URLs

Publishing tools may retrieve an asset from:

```text
https://raw.githubusercontent.com/strlenstrlen/navastra-media/main/<path>
```

Do not rewrite or remove a published asset. Add a versioned replacement so scheduled and historical posts retain a stable source URL.
